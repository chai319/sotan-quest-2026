# 高2ソウタン「四天王クエスト」進行Webサイト

**四天王を倒して楽園への扉をひらけ！ 〜高2ソウタン 9/30 DX進行クエスト〜**

滋賀県立河瀬高等学校 2学年「総合的な探究の時間（ソウタン）」（90分）において、生徒がAI（Gemini）と対話しながら外部調査企画をブラッシュアップするためのドラクエ風レトロJRPG進行Webアプリケーションです。

---

## 🚀 特徴・教育設計（S.L.O.W. 原則準拠）

1. **8bitレトロJRPGゲーミフィケーション**:
   - ドラクエ風の黒背景・白二重枠・コマンド式インターフェースで探究の試練を演出。
   - 四天王4体（曖昧王・既知王・丸投げ王・空論王）、勇者パーティ、武器アイコンはすべて**完全オリジナルのインラインSVGドット絵**。
2. **人間工学・認知負荷抑制（`kawase-cognitive-visual-design` 準拠）**:
   - 左上に「工程番号＋今すること」、右下に「主操作ボタン」を配した**Z型・F型視線誘導**。
   - 各Stage（0〜4）に**16:9解説動画スペース**を完備。
   - 5大Gemini呪文プロンプトのワンクリックコピー＆起動リンク。
3. **iPad（iPadOS / Safari）完全最適化**:
   - **全タブ入力保持**: ボスを切り替えても四天王4体それぞれの入力内容が消えない個別ステート管理＆`localStorage`自動保存。
   - **A4印刷・PDF出力**: 「🖨️ A4レポート印刷 / iPadでPDF保存」から、全入力内容が文字切れなく美しくレイアウトされたA4提出用サマリーシートを自動生成。プリント画面で2本指ピンチアウトすれば、即座にPDF化して「ファイルに保存」や「ロイロノート」へ提出可能。
   - **ロイロノート提出用テキスト一括コピー**: PDF化が難しい環境でも、ワンクリックで全入力をフォーマットされたテキストとしてクリップボードへコピー可能。
4. **ゼロ外部依存（完全スタンドアロン）**:
   - 外部画像ファイルなし、外部CSS/JSライブラリ（CDN）なし。
   - 効果音（SE）もブラウザ標準の **Web Audio API** によるシンセサイザーで生成（音源ファイル不要・著作権侵害ゼロ）。
   - 単一の `index.html` だけで、オフラインや学校の厳格なWebフィルタリング環境下でも100%動作します。

## 🌐 GitHub Pages 公開手順

本フォルダ内の `index.html` は、GitHub Pagesですぐに公開できるように最適化されています。

### 方法A: リポジトリのルートに配置する場合
1. GitHub上に新しいパブリックリポジトリ（例: `sotan-quest-2026`）を作成。
2. 本リポジトリのルートに `index.html` をコミット＆プッシュ。
3. リポジトリの **Settings** ➔ **Pages** を開く。
4. **Build and deployment** の Source で **Deploy from a branch** を選択。
5. Branch を `main`、フォルダを `/ (root)` に設定して **Save**。
6. 数十秒後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。

### 方法B: 既存リポジトリの `/docs` フォルダに配置する場合
1. 既存リポジトリ内の `docs/` ディレクトリに `index.html` を配置。
2. **Settings** ➔ **Pages** で Branch を `main`、フォルダを `/docs` に設定して **Save**。

## 📱 生徒用 iPad 操作ガイド（PDF提出手順）

1. **入力**: Stage 1〜4を進めながら、武器の選定理由、四天王4体の判定記録、工程表、冒険の書を入力します。
2. **提出メニュー**: 画面上部ヘッダーの「📄 提出/PDF」またはStage 4の「🖨️ A4レポート印刷 / iPadでPDF保存」をタップ。
3. **PDF保存（iPadの標準機能）**:
   - 印刷プレビュー画面が表示されたら、用紙プレビューを**2本指で外側に広げる（ピンチアウト）**。
   - 全画面のPDFプレビューが開くので、右上の**共有ボタン（四角と上矢印 ⎋）**をタップ。
   - **「ファイルに保存」** または **「ロイロノート」** を選択して提出完了！
4. **ロイロノート直接提出**:
   - 「📋 ロイロノート提出用テキスト一括コピー」をタップすると、全入力がコピーされるので、ロイロノートのカードに貼り付けて即提出できます。
